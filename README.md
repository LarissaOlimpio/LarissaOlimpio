## 🤖 Como eu uso IA

- **Codex CLI** no desenvolvimento dos meus projetos, utilizando arquivos de contexto (.md) para orientar a IA sobre a arquitetura e as necessidades de cada projeto.
- **Eu decido** arquitetura, segurança e escopo; a IA acelera a implementação, os testes e a documentação.
- **Eu reviso tudo**: leio, testo e entendo cada trecho antes de integrá-lo ao código.
